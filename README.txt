Picture Talk - upload guide (GitHub Pages)

1. Create a new GitHub repository (e.g. "picture-talk"), public.
2. Upload ALL files in this folder to the repository root (index.html, sw.js, manifest.webmanifest, icon-512.png). Keep the file names exactly as they are.
3. Repository Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root). Save.
4. After a minute your app is at https://<your-username>.github.io/picture-talk/
5. Open that link on the iPad/phone > Share > Add to Home Screen.

Updating later: replace index.html and sw.js. Close and reopen the app (or remove and re-add it) if you still see the old version.

word-blocks-print.pdf is for printing only; the app does not need it (you can leave it out of the repository).
